The **`layout`** package collects **wayfinding**, **form page structure**, and **global confirm dialogs** so list and form screens feel consistent across apps in the monorepo.

## When to use it

| Component | Use when |
| --- | --- |
| `Breadcrumbs` | Hierarchical routes with a shared trail |
| `GoBackButton` | Detail pages that should return to a list or parent |
| `FormSection` / `FormLayout` | Group fields with title, description, and spacing |
| `EmptyState` / `ContentEmpty` | Zero-data placeholders with optional actions |
| `ConfirmationDialogProvider` | Any destructive or irreversible action |
| `UtilityIconButton` | Docs, refresh, and info affordances in toolbars |

## Installation

<DocsInstall
  packages={["layout"]}

  Breadcrumbs,

  EmptyState,

import { ConfirmationDialogProvider, useConfirmationDialog } from "layout/confirmation-dialog"`}
/>

Register **`ConfirmationDialogProvider`** once near the root (before any `useConfirmationDialog` call):

```tsx
// apps/web/src/app/providers.tsx
<ConfirmationDialogProvider>
  {children}
</ConfirmationDialogProvider>
```

## Usage

### Breadcrumbs

<ComponentPreview code={`import { Breadcrumbs } from "layout"

// Reads route segments / your app's breadcrumb config
<Breadcrumbs />`}>
  <BreadcrumbsDemo />
</ComponentPreview>

Pair with **`GoBackButton`** on nested detail routes:

```tsx
import { GoBackButton } from "layout"

<GoBackButton fallbackHref="/docs" />
```

### Form sections

```tsx
import { FormSection } from "layout"

<FormSection title="Account" description="Identifiers visible to admins.">
  {/* FormKit.Field children */}
</FormSection>
```

`FormLayout` and `FormLayoutActionsHint` help align action bars on long forms (sticky footers, scroll hints).

### Confirmation dialog

```tsx
"use client"

import { useConfirmationDialog } from "layout/confirmation-dialog"

const { confirm } = useConfirmationDialog()

const ok = await confirm({
  title: "Delete row?",
  description: "This cannot be undone.",
  variant: "destructive",
  confirmLabel: "Delete",
})

if (ok) {
  await deleteRow()
}
```
