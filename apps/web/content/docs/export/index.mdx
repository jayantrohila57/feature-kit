The `export` package provides small utilities to serialize tabular data for download.

## Installation

```tsx
import { buildCsvContent, exportToCsv } from "export/csv"
import { exportToXlsx } from "export/xlsx"
import type { ExportColumn } from "export"
```

## Usage

Bulk export buttons in `data-table/bulk` call these helpers with the current selection. For custom export buttons:

```tsx
import { exportToCsv } from "export/csv"

exportToCsv({
  filename: "report.csv",
  columns: exportColumns,
  rows: selectedRows,
})
```

## API

| Export | Description |
| --- | --- |
| `buildCsvContent` | Build CSV string |
| `exportToCsv` | Trigger browser download |
| `exportToXlsx` | Excel workbook download via `xlsx` |

## Notes

- Depends on workspace `xlsx` catalog version.
- See [Bulk actions](/docs/data-table/bulk-actions) for integrated UI.
