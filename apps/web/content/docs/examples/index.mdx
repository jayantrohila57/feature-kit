Examples are **isolated previews** embedded in the docs site. Each page mounts one scenario so you can compare behavior before copying code into your app.

Kit overview pages ([Form](/docs/form), [Data table](/docs/data-table), etc.) hold installation steps, props tables, and gotchas. Use this index to jump straight to a scenario.
