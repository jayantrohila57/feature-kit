## What this demonstrates

This is a complete create/edit shape: a Zod input schema, typed default values, a `FormSection`, text/select/switch fields, and action controls. The submit handler waits briefly to make the pending state visible, then resets the form because `resetOnSuccess` is enabled.

Use this example when the form owns its values and has a single submit lifecycle. Replace the demo toast and delay with the mutation used by your application.
