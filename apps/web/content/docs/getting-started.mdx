Feature Kit is a **pnpm monorepo** of workspace packages. This guide gets a fresh checkout running, then points to the foundation pages for application integration.

## Prerequisites

- **Node.js 24+**
- **pnpm 9+**

## Run the playground

```bash
git clone https://github.com/jayantrohila57/feature-kit.git
cd feature-kit
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) for the landing page and [/docs](/docs) for kit documentation with live previews.

Production build (Vercel uses `apps/web` as the app root):

```bash
pnpm build
```

## Monorepo layout

| Path | Contents |
| --- | --- |
| `apps/web` | Next.js docs site and examples |
| `feature/*` | Kits: `form`, `data-table`, `layout`, `uploader`, … |
| `packages/ui` | Shared shadcn-style primitives |
| `packages/format`, `packages/config` | Helpers and TS config |

## Add a kit to your app

<DocsInstall
  packages={["form", "data-table", "layout"]}

List every workspace kit you import in **`transpilePackages`** inside `apps/web/next.config.ts`. See [Installation](/docs/installation) for the complete integration path.

## Configure providers

Most examples assume the playground providers in `apps/web/src/app/providers.tsx`. Their roles and a reusable composition are documented in [Providers](/docs/providers).

| Provider | Package | Purpose |
| --- | --- | --- |
| `NextIntlClientProvider` | `next-intl` | Table pagination, confirms, field copy |
| `ThemeProvider` | `next-themes` | Light/dark |
| `ConfirmationDialogProvider` | `layout` | `useConfirmationDialog` |
| `DataTableNuqsAdapter` | `data-table` | URL sync for listings |
| `TooltipProvider` | `ui` | Tooltips in tables and fields |

| Package | Role |
| --- | --- |
| `export` | CSV/XLSX download helpers (table bulk export, uploader templates) |
