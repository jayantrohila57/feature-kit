## Run locally

Requires Node.js 24+ and pnpm 9+.

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000), then open [/docs](/docs) for kit overviews and live previews.

Production build (Vercel uses `apps/web` as the app root):

```bash
pnpm build
```

## Use a kit in the monorepo

Add a workspace dependency in your app’s `package.json`:

```json
"form": "workspace:*"
```

List the package in `transpilePackages` in `next.config.ts` (see `apps/web` for the full list).

Import by package name:

```tsx
import { FormKit } from "form"
import { DataTable } from "data-table"
import { FormSection, Breadcrumbs } from "layout"
```

The web app wraps providers you’ll often need—`DataTableNuqsAdapter` for URL-synced tables and `ConfirmationDialogProvider` for confirms (`apps/web/src/app/providers.tsx`).

## Other workspace packages

- **`export`** — CSV/XLSX download helpers (used by table bulk export)
- **`format`** — masks and locale-aware formatting
- **`preferences`** — theme/locale cookies for host apps

Details live in each package’s `package.json` `exports` and in the source under `feature/*` and `packages/*`.
