title: Blocks

---

Blocks are **complete screens** composed from the kits: dashboard shell, tables, forms, auth, uploader, and theme. Each block includes a live preview with mobile, tablet, and desktop widths, copyable source, and a shadcn registry install.

## How blocks differ from examples

| | Examples | Blocks |
| --- | --- | --- |
| Scope | Focused kit demos | Full-page product UI |
| Preview | In-page component | Iframe + viewport toggle |
| Install | Kit-level registry | Per-block registry item |

Start from the [installation](/docs/installation#registry) registry setup, then run the CLI on any block page.
