`format` builds on `preferences` to resolve effective locale/theme and expose formatting helpers for UI and server code.

## Installation

```tsx
import { maskEmail } from "format/mask"
// server-only utilities: format/server
```

Exports: `.`, `./effective-preferences`, `./presets`, `./server`, `./ui`, `./hooks`, `./mask`.

## Usage

Use mask helpers for display-only field formatting:

```tsx
import { maskEmail } from "format/mask"

maskEmail("user@example.com")
```

Server modules gate behind `server-only` for Next.js RSC routes.

## Notes

- `data-table` depends on `format` for display helpers in column renderers.
- See `packages/format/src` for preset catalogs and hook entry points.
