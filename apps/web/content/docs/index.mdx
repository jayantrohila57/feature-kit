**Feature Kit** is a pnpm monorepo of workspace packages (`form`, `data-table`, `layout`, `uploader`, `ui`, and a few helpers) built on shadcn-style primitives, React Hook Form, Zod, and TanStack Table.

Use it when you want **copy-paste-friendly patterns** for common product screens—not a hosted SaaS. This site runs the kits in **`apps/web`**: short kit pages explain the basics; **live previews** on each kit page and under [Examples](/docs/examples) show them running.

## Kits at a glance

| Package | Use for |
| --- | --- |
| [Form](/docs/form) | Schema-driven forms (`FormKit`) and inline filters (`FieldKit`) |
| [Data table](/docs/data-table) | Sortable, filterable lists with selection and bulk actions |
| [Layout](/docs/layout) | Breadcrumbs, back button, form sections, confirm dialogs |
| [Uploader](/docs/uploader) | CSV/XLSX import dialog with validation |
| [UI](/docs/ui) | Shared buttons, fields, tables, and global styles |

Start with [Getting started](/docs/getting-started) to run the repo locally.
