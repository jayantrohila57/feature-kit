**Feature Kit** is a pnpm monorepo of workspace packages built on shadcn-style primitives, React Hook Form, Zod, and TanStack Table. It targets **product engineers** who want opinionated, copy-friendly patterns for admin UIs—not a hosted component SaaS.

This documentation site runs the kits inside **`apps/web`**: each kit page includes **live previews**, **install snippets**, **usage recipes**, and **props tables** sourced from the real TypeScript types in `feature/*`.

## How to read these docs

Pages follow a consistent structure (similar to shadcn/ui app docs):

1. **When to use** — choose the right kit or API
2. **Installation** — workspace dependency + import
3. **Preview + code** — toggle between live UI and sample source
4. **Recipes** — common combinations (URL sync, server errors, bulk actions)
5. **API reference** — props tables aligned with source types
6. **Gotchas** — pitfalls we hit in production apps
7. **Examples** — links to focused previews under `/docs/examples`

## Kits at a glance

| Package | Use for |
| --- | --- |
| [Form](/docs/form) | Schema-driven forms (`FormKit`) and inline filters (`FieldKit`) |
| [Data table](/docs/data-table) | Sortable, filterable lists with selection and bulk actions |
| [Layout](/docs/layout) | Breadcrumbs, back button, form sections, confirm dialogs |
| [Uploader](/docs/uploader) | CSV/XLSX import dialog with validation |
| [UI](/docs/ui) | Shared buttons, fields, tables, and global styles |
