The toolbar is rendered automatically by `DataTable`. Customize it with column meta, `filterDefinitions`, and slot props.

<PlaygroundLink href="/examples/table/filters">DataTable — filters</PlaygroundLink>

## Installation

```tsx
import {
  DataTableToolbar,
  DataTableActiveFilterBar,
  DataTableAppliedFilters,
} from "data-table/toolbar"
```

Most apps rely on the built-in toolbar inside `DataTable`; import these when building custom layouts.

## Search

`displayKey` selects which column powers the default search input. For global server search, set `toolbarSearchPlaceholderKey` to an i18n key instead of the default “Filter by …” pattern.

## Column menus

`DataTableToolbarColumnMenus` and `DataTableViewOptions` (from `data-table/view-options`) control visibility and per-column filter UI.

## Slots

| Prop | Position |
| --- | --- |
| `toolbarLeading` | Before search |
| `toolbarAfterSearch` | After search, before filter chips |
| `toolbarTrailing` | After column visibility toggle |

## Notes

- Filter chips use `DataTableToolbarFilterChip` / `DataTableToolbarFilterChips` internally.
- `DataTableToolbarAddFilterMenu` lists filters not yet applied.
