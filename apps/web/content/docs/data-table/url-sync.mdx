When `syncUrl` is `true` (default), table state is mirrored in the URL for shareable list views.

<PlaygroundLink href="/examples/table/url-sync">DataTable — URL sync</PlaygroundLink>

## Installation

```tsx
import { DataTableNuqsAdapter } from "data-table"
import { useEffectiveSearchParams, useTableUrlSync } from "data-table/utils"
```

Mount `DataTableNuqsAdapter` once near the root (see [Installation](/docs/installation)).

## DataTable flags

| Prop | Purpose |
| --- | --- |
| `syncUrl` | Master toggle; set `false` for embedded tables |
| `urlShallow` | Shallow routing without RSC refetch (default suited to client queries) |
| `urlServerRefresh` | Refetch server components after URL writes on server-driven lists |
| `canonicalizeUrl` | Skip writing default `page`/`limit` on mount when `false` |

## Client queries

Listing pages that fetch with TanStack Query should read params via `useEffectiveSearchParams` so shallow URL updates trigger refetches.

## Notes

- Embedded audit tables on detail pages usually set `syncUrl={false}` to avoid polluting parent URLs.
- Row actions example: [/examples/table/row-actions](/examples/table/row-actions).
