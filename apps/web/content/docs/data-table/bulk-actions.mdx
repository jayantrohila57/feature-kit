Pass a `bulkActions` node to `DataTable`—typically a `BulkActionBar` with action buttons.

<PlaygroundLink href="/examples/table/bulk-actions">DataTable — bulk actions</PlaygroundLink>

## Installation

```tsx
import {
  BulkActionBar,
  BulkClearSelectionAction,
  BulkExportCsvAction,
  BulkExportXlsxAction,
} from "data-table/bulk"
```

## Usage

```tsx
<DataTable
  bulkActions={
    <BulkActionBar>
      <BulkExportCsvAction filename="people.csv" />
      <BulkClearSelectionAction />
    </BulkActionBar>
  }
  // columns with selectColumn, selectionKey, etc.
/>
```

Export actions use the `export` package (`exportToCsv`, `exportToXlsx`) under the hood.

## Notes

- Selection must be enabled and `selectionKey` provided for counts in the bar.
- `bulkActionButtonClassName` styles action buttons consistently with the toolbar.
