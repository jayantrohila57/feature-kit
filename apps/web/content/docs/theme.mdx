The **`theme`** package wraps `next-themes` and syncs the active theme into the `preferences` storage key via `applyThemePreference` (no extra DOM writes).

## When to use it

| Export | Use when |
| --- | --- |
| `ThemeProvider` | App root — replaces raw `next-themes` provider |
| `ThemeToggle` | Icon button cycling light/dark |
| `ThemeSelector` | Light / dark / system dropdown |
| `ThemePreferenceSync` | Advanced: mount inside a custom provider |

## Usage

Replace the raw `ThemeProvider` from `next-themes` with the kit provider (already wired in the playground `Providers`):

```tsx
import { ThemeProvider } from "theme"

<ThemeProvider attribute="class" defaultTheme="system" enableSystem>
  {children}
</ThemeProvider>
```

`ThemePreferenceSync` runs automatically when `syncPreferences` is true (default). It mirrors `light`, `dark`, and `system` into the same localStorage key used by `preferences` bootstrap.
