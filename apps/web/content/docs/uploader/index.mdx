`CommonUploaderButton` opens a dialog to pick CSV/XLSX files, parse rows, validate against column rules, and submit through your handler.

<PlaygroundLink href="/examples/uploader/basic">Uploader — basic</PlaygroundLink>

## Installation

```tsx
import {
  CommonUploaderButton,
  type UploaderConfig,
  parseSpreadsheetFile,
  validateUploaderRecords,
  downloadUploaderTemplate,
} from "uploader"
```

## Usage

```tsx
<CommonUploaderButton
  config={config}
  triggerLabel="Import accounts"
  redirectOnSuccess={false}
  onUpload={async ({ records }) => ({
    success: true,
    message: `Imported ${records.length} rows`,
  })}
/>
```

## UploaderConfig

| Field | Description |
| --- | --- |
| `entity` | Stable entity code for forms/APIs |
| `entityLabel` | Human label for toasts |
| `title` / `description` | Dialog copy |
| `fileFormat` | Format code (e.g. `standard`) |
| `templateFileName` | Download filename without extension |
| `acceptedFileTypes` | e.g. `.xlsx,.csv` |
| `columns` | `UploaderColumn[]` with `key`, `header`, `requiredIn` per mode |
| `defaultMode` | `create` or `update` |
| `transport` | `records` (parse) or `file` (raw upload) |
| `validateParsedRecords` | Optional cross-row validation |
| `historyHref` / `buildSuccessRedirectHref` | Post-success navigation |

## Column definition

```ts
{
  key: "email",
  header: "Email",
  requiredIn: ["create"],
  sample: "user@example.com",
}
```

## Transport modes

- **`records`** (default) — parses spreadsheet in the browser, runs `validateUploaderRecords`, passes `records` to `onUpload`.
- **`file`** — uploads the raw file; `columns` are not required.
