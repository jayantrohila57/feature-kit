FormKit wraps React Hook Form and Zod in a declarative API: one schema, default values, and `FormKit.Field` children for each control.

<PlaygroundLink href="/examples/form/basic">FormKit — basic</PlaygroundLink>

## Installation

Add the workspace package and transpile it in Next.js (see [Installation](/docs/installation)).

```tsx
import { FormKit } from "form"
import { FormSection } from "layout"
```

Subpaths: `form/form-kit`, `form/field`, `form/field-kit`.

## Usage

```tsx
<FormKit schema={schema} defaultValues={defaults} onSubmit={handleSubmit} resetOnSuccess>
  <FormSection title="Account">
    <FormKit.Field type="text" name="email" label="Email" required />
  </FormSection>
  <FormKit.Actions>
    <FormKit.Reset label="Reset" />
    <FormKit.Submit label="Save" pendingLabel="Saving…" />
  </FormKit.Actions>
</FormKit>
```

`FormKit.Submit` respects `isPending` on the root when you drive async submits from the parent.

## Recipes

### Sections and footer actions

Use `FormSection` from `layout` for titled groups. Place `FormKit.Actions` after sections for a sticky-style footer pattern used across create/edit flows.

### Scroll layout

Set `scrollBody={false}` when the page shell (not FormKit) owns vertical scrolling—useful for multi-section wizards.

### Server errors

Pass `mapServerError` to translate API failures into field-level errors, or call `applyServerErrors` from `form` inside `onSubmit` catch blocks.

## API

| Prop | Type | Description |
| --- | --- | --- |
| `schema` | `ZodType` | Validates on submit; infers value types |
| `defaultValues` | `DefaultValues` | Initial field values |
| `onSubmit` | `(values) => void \| Promise<void>` | Called with Zod output on success |
| `isPending` | `boolean` | Disables submit and shows pending label |
| `resetOnSuccess` | `boolean \| "keepDirtyValues" \| DefaultValues` | Resets form after successful submit |
| `mapServerError` | `(error: unknown) => MapServerErrorResult` | Maps API errors to RHF field errors |
| `translateError` | `(message: string) => string` | Localize Zod/server message keys |
| `onSuccess` / `onError` | callbacks | Lifecycle hooks around submit |
| `scrollBody` | `boolean` | Default `true`; inner scroll vs page scroll |
| `className` | `string` | Root layout class |

`FormKit.Field` accepts any `FieldType` registered in `fieldRegistry` (see [Field types](/docs/form/field-types)).

## Notes

- Re-exported hooks: `useFormContext`, `useFormState`, `useWatch`, `Controller` from `form`.
- `useFormKitMeta` exposes pending/success metadata for custom action rows.
- For filter bars without submit, use [FieldKit](/docs/form/field-kit) instead.
