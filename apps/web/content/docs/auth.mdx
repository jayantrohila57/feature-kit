The **`auth`** workspace package wraps [better-auth](https://www.better-auth.com/) with Feature Kits form patterns, card layouts, and sign-out affordances. The docs playground runs in **demo mode** (in-memory database, no GitHub or database environment variables).

## When to use it

| Export | Use when |
| --- | --- |
| `SignInForm` / `SignUpForm` | Email/password flows with Zod + FormKit |
| `AuthProviders` / `GitHubSignInButton` | Social sign-in row above the form |
| `AuthCardLayout` | Consistent auth page chrome |
| `useSession` / `signOut` | Client session from better-auth |
| `auth` (`auth/server`) | Next.js route handler (`/api/auth/[...all]`) |

### API route

```tsx
// apps/web/src/app/api/auth/[...all]/route.ts
import { auth } from "auth/server"
import { toNextJsHandler } from "better-auth/next-js"

export const { GET, POST } = toNextJsHandler(auth)
```

## Demo mode

`auth/server` uses the memory adapter and a fixed development secret when `DATABASE_URL` or GitHub OAuth credentials are missing. Sessions reset on serverless cold starts. Set `AUTH_DEMO_MODE=false` and provide production secrets to disable demo defaults.

## API reference

### `AuthSchema`

Zod input objects for `SIGN_IN`, `SIGN_UP`, `FORGOT_PASSWORD`, `RESET_PASSWORD`, and `VERIFY_EMAIL`. Import from `auth/schema` when you need types without UI.
