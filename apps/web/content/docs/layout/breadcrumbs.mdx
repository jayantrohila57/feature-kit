`Breadcrumbs` reads the current Next.js pathname and renders a trail with optional actions.

<PlaygroundLink href="/examples/layout/breadcrumbs">Layout — breadcrumbs</PlaygroundLink>

## Installation

```tsx
import { Breadcrumbs, BreadcrumbsSkeleton } from "layout"
// or layout/breadcrumb
```

## Usage

```tsx
<Breadcrumbs />
```

Use `BreadcrumbsSkeleton` while layout metadata is loading.

## Notes

- Examples layout places breadcrumbs beside `GoBackButton` above the main column.
- Integrates with next-intl message keys where segments define labels in your host app.
