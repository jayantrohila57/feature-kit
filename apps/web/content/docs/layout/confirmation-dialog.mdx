---
title: Confirmation dialog
description: App-wide confirmation provider and imperative confirm API.
---

Destructive row actions and bulk operations use the confirmation dialog to block accidental deletes.

## Installation

```tsx
import {
  ConfirmationDialogProvider,
  useConfirmationDialog,
} from "layout/confirmation-dialog"
```

Mount the provider once (see `apps/web/src/app/providers.tsx`).

## Usage

```tsx
const confirm = useConfirmationDialog()

await confirm({
  title: "Delete row?",
  description: "This cannot be undone.",
  confirmLabel: "Delete",
  variant: "destructive",
})
```

## Notes

- `ConfirmationDialog` can also be used declaratively when you prefer controlled state.
- Row actions example: [/examples/table/row-actions](/examples/table/row-actions).
